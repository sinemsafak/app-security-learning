
# App Security Learning

Güvenli web ve mobil uygulama geliştirmeyi öğrenmek için
hazırlanan eğitim projesi.

## Projenin hedefleri

- Tehdit modellemesi yapmak
- API tarafında kimlik doğrulama ve yetkilendirme uygulamak
- Kullanıcıların özel verilerini korumak
- Web ve mobil istemcileri aynı API'ye bağlamak
- Güvenlik testlerini ve GitHub iş akışını öğrenmek

## Klasörler

- `notes/`: Tehdit modeli ve güvenlik notları
- `web-app/`: Web istemcisi
- `mobile-app/`: Mobil istemci
- `api/`: API sunucusu (sonraki aşamada oluşturulacak)

## Güvenlik uyarısı

Bu proje eğitim amaçlıdır. Gerçek kullanıcı verileri veya gerçek
üretim sırları kullanmayın. Üretim ortamında kullanmadan önce
güvenlik incelemesi, yapılandırma sertleştirmesi ve dağıtım
kontrolleri gereklidir.

## Geliştirme

Kurulum ve çalıştırma adımları uygulama klasörleri tamamlandıkça
bu belgeye eklenecektir.
